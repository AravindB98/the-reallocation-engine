# SUBMISSION

## Executive summary

**What this is.** The cover sheet for my Mode Build submission: a job-search mode for an international data-analytics student who is on a student visa, has not started post-study work authorization, and needs an employer that has sponsored *entry-level data* jobs.

**Why read it.** It says where every deliverable is, which exact version of the code the zip was built from, and what the mode honestly cannot do yet.

**What it found.** The mode ran on sample data and on five real job postings. Its "is the posting still open?" gate stopped every closed posting. It also recommended Apply for a *Senior* posting, because it checks the seniority of the jobs an employer has sponsored but not of the posting itself. That gap is recorded as a proposed fix. The honest status is a draft.

## Known limitations

- **Posting seniority is not checked.** On 2026-10-21 an open Senior Data Scientist posting (5+ years) was recommended Apply. This is proposed addition 8; until it is built, a person must treat a senior posting title as Skip.
- **Liveness is copied by hand.** npm run ats:liveness runs, but its result is not fed into the posting automatically (proposed addition 4).
- **Recency.** Approval and denial counts carry no year.
- **Primary sources.** The CSV was not cross-checked against DOL or USCIS records, and a name match may not be the posting's actual employer.
- **Unmarked titles.** Titles with no level marker are treated as entry-or-unmarked; unmarked is not proof of entry level.
- **Fit.** Held constant at 0.5.
- **Duplicate evidence.** Duplicate employer rows (PATHAI/PATHRAI, Peloton INC/LLC) carry identical evidence and are only compared within a run.
- **Report labels.** The generated report labels a real run as "sample" and prints None for missing titles.
- **CI.** CI on PR #56 has run no jobs: every workflow run is action_required, waiting for maintainer approval. The conformance evidence is local: npm run verify and npm run doctor -- --strict both exit 0.
- **Where the posting URLs came from.** The five real posting URLs were found by Claude in a claude.ai chat session using web search on 2026-10-21. I chose to use them, ran the liveness checks and the browser check myself.
