# Note on this run folder

## Executive summary

This folder is the student's round-2 run, copied as it ran, with one change: an email address that appeared in a
company's own posting text was replaced with "[email removed]" in `report.md` and `run-log.json`. The address was a
company contact address (for accommodation requests), not a person's. It is removed because the repository's privacy
scan treats every email address as private data. The unedited files are kept outside the repository.

## Why it appeared

Version 0.2.1 keeps every line it reads visible, including lines under headings that are not requirements, at the
student's request. One Figma posting has a line with a contact address under such a heading. Version 0.2.1 does not
remove addresses from posting lines; that is recorded in the worked run as found, not fixed.
