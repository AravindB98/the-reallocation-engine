# o7580 — Recipe Design Assignment (Fall 2026)

## Executive summary

This folder holds the written half of my submission for a recipe that helps a December-graduating international student in Boston pick which junior software postings deserve application time. It sorts them by whether the employer has sponsored *junior* software engineers, and by whether hiring fits inside the OPT unemployment window. Start with the domain justification for the why, then the worked run for what actually happened. The code is in `scripts/contrib/2026fa/o7580-decgrad-swe1-sponsor-level/`, and the recipe is in `recipes/cases/2026fa/`.
